# UPC Conflict Resolver - Premium SaaS

A modern, enterprise-grade UPC conflict resolution and inventory management system.

## Features

- 📊 Advanced dashboard with real-time analytics
- 🚀 Drag-and-drop file upload (Excel/CSV)
- 🎨 Premium UI with animations and 3D effects
- ⚡ High-performance Next.js 14 architecture
- 🎯 Smart duplicate detection and conflict resolution
- 📈 Interactive charts and visualizations
- 🌓 Dark mode support
- ⌨️ Command palette (Cmd/Ctrl+K)

## Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **UI**: Tailwind CSS, Radix UI, Framer Motion
- **Charts**: Chart.js, Recharts
- **Backend**: Prisma, Express
- **Deployment**: Vercel

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Keyboard Shortcuts

- `Cmd/Ctrl + K` - Open command palette
- `G then H` - Go to dashboard
- `G then U` - Go to upload
- `G then C` - Go to conflicts

## Deployment

This application is configured for automatic deployment on Vercel. Simply push to your main branch to deploy.
